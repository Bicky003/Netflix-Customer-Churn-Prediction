# Power BI Dashboard Implementation & DAX Guide

This guide provides step-by-step instructions to create an executive, publication-ready Power BI Dashboard using the machine learning outputs generated by the churn prediction model (`processed_netflix_churn_with_predictions.csv`, `churn_model_metrics.csv`, `feature_importance.csv`, `churn_kpi_summary.csv`).

---

## 1. Data Model Architecture (Star Schema)

Import the following exported CSV/Excel files into Power BI Desktop:

1. **`processed_netflix_churn_with_predictions`** (Fact Table)
   - Contains customer demographics, usage activity, engineered features, predicted churn probabilities (`churn_probability`), binary prediction flag (`predicted_churn_flag`), risk tier (`churn_risk_segment`), and primary risk driver (`primary_risk_driver`).
2. **`churn_model_metrics`** (Dimension / Benchmark Table)
   - Model metrics across Logistic Regression, Random Forest, XGBoost, LightGBM, and Gradient Boosting.
3. **`feature_importance`** (Dimension Table)
   - Ranked list of features, importance weights, and importance percentages.
4. **`churn_kpi_summary`** (Aggregate KPI Table)
   - Regional, plan tier, and risk level aggregated summary metrics.

### Relationships:
- `processed_netflix_churn_with_predictions[churn_risk_segment]` ─── (1:N) ─── `churn_kpi_summary[churn_risk_segment]`
- `processed_netflix_churn_with_predictions[subscription_type]` ─── (1:N) ─── `churn_kpi_summary[subscription_type]`

## 2. Complete DAX Measures Library

Create a new table in Power BI named `_DAX_Measures` and add the following DAX calculations:

```dax
// ==========================================
// 1. CUSTOMER COUNT & CHURN KPIs
// ==========================================

Total Customers = COUNTROWS('processed_netflix_churn_with_predictions')

Actual Churn Count = SUM('processed_netflix_churn_with_predictions'[churned])

Actual Churn Rate % = DIVIDE([Actual Churn Count], [Total Customers], 0)

Predicted Churn Count = SUM('processed_netflix_churn_with_predictions'[predicted_churn_flag])

Predicted Churn Rate % = DIVIDE([Predicted Churn Count], [Total Customers], 0)

Avg Churn Probability % = AVERAGE('processed_netflix_churn_with_predictions'[churn_probability_pct])

// ==========================================
// 2. CHURN RISK SEGMENTATION KPIs
// ==========================================

High Risk Customers = 
CALCULATE(
    [Total Customers],
    'processed_netflix_churn_with_predictions'[churn_risk_segment] = "High Risk"
)

Medium Risk Customers = 
CALCULATE(
    [Total Customers],
    'processed_netflix_churn_with_predictions'[churn_risk_segment] = "Medium Risk"
)

Low Risk Customers = 
CALCULATE(
    [Total Customers],
    'processed_netflix_churn_with_predictions'[churn_risk_segment] = "Low Risk"
)

High Risk % = DIVIDE([High Risk Customers], [Total Customers], 0)

// ==========================================
// 3. REVENUE AT RISK DAX MEASURES
// ==========================================

Total Monthly Revenue = SUM('processed_netflix_churn_with_predictions'[monthly_fee])

Total Annualized Revenue = SUM('processed_netflix_churn_with_predictions'[annual_revenue])

Monthly Revenue at Risk = SUM('processed_netflix_churn_with_predictions'[monthly_revenue_at_risk])

Annual Revenue at Risk = SUM('processed_netflix_churn_with_predictions'[annual_revenue_at_risk])

Revenue Risk % = DIVIDE([Monthly Revenue at Risk], [Total Monthly Revenue], 0)

// ==========================================
// 4. MODEL PERFORMANCE & QUALITY METRICS
// ==========================================

Best Model ROC AUC = 
CALCULATE(
    MAX('churn_model_metrics'[ROC_AUC]),
    'churn_model_metrics'[Model] = "Gradient Boosting"
)

Best Model Accuracy % = 
CALCULATE(
    MAX('churn_model_metrics'[Accuracy]),
    'churn_model_metrics'[Model] = "Gradient Boosting"
)

Best Model F1 Score = 
CALCULATE(
    MAX('churn_model_metrics'[F1_Score]),
    'churn_model_metrics'[Model] = "Gradient Boosting"
)
```

## 3. Power BI Page Layout & Visual Specifications

### 🎨 Theme & Color Palette (Netflix Dark Design):
- **Page Canvas Background**: `#141414` (Dark Charcoal)
- **Visual Container Cards**: `#1F1F1F` with subtle border `#333333`
- **High Risk / Alert Color**: `#E50914` (Netflix Red)
- **Medium Risk Color**: `#FFA500` (Amber Gold)
- **Low Risk / Safe Color**: `#2ECC71` (Emerald Green)
- **Primary Text**: `#FFFFFF` (Bright White)
- **Secondary Text**: `#B3B3B3` (Light Gray)

## 4. Power BI Desktop Step-by-Step Publishing Guide

1. **Open Power BI Desktop** ➔ Click `Get Data` ➔ Select `Text/CSV` or `Excel Workbook`.
2. Load `processed_netflix_churn_with_predictions.csv` and `churn_model_metrics.csv`.
3. In `Model View`, create relationships as defined in Section 1.
4. Go to `Report View` ➔ Set Canvas Background to `#141414` (Transparency: 0%).
5. Add DAX Measures from Section 2 into a blank table.
6. Assemble visuals for Page 1, Page 2, and Page 3 as structured above.
7. Apply custom theme colors (`#E50914` for High Risk, `#2ECC71` for Low Risk).
8. Save file as `Netflix_Customer_Churn_Dashboard.pbix`.
9. Click `Publish` to upload to Power BI Service / Workspace for executive sharing.
